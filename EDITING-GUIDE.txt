MDM CREATION WEBSITE — EDITING GUIDE

1. Open the "dist" folder in Visual Studio Code.
2. Open "index.html" to edit the website.
3. Text, prices, links, colors, layout, and bilingual content are all contained in index.html.
4. Replace images inside "dist/assets" while keeping the same filenames, or update the image filenames in index.html.
5. Double-click index.html to preview the website in your browser.
6. To publish on Netlify, upload the complete "dist" folder.

Language toggle:
- Only text wrapped in both data-en and data-es spans changes when the ES/EN button is clicked.
- Keep shared content such as brand names, prices, package names, and domain names outside those spans so it stays the same in both languages.
- Example: <span data-en>Services</span><span data-es>Servicios</span>
- The page title, image text, and footer details are intentionally not translated.

Service pages:
- Each service card on the homepage links to its own page inside "dist/services".
- dist/services/branding.html — Branding & Logo Design
- dist/services/websites.html — Website Design
- dist/services/tapcard.html — MDM TapCard
- dist/services/merchandise.html — Custom Merchandise
- dist/services/marketing.html — Marketing Design
- dist/services/support.html — Business Support
- dist/services/social.html — Social Media
- dist/services/service.css and service.js are shared by all service pages.

Automatic project gallery:
- The homepage loads approved MDM TapCard AutoGallery photos in the "Our Projects" section.
- Keep MDM_API_KEY only in Netlify environment variables; never put it in frontend JavaScript.
- Copy the values from `.env.example` into Netlify Site configuration → Environment variables.
- Set MDM_BUSINESS_SLUG to the slug shown in MDM TapCard → Admin → Website Feed.
- Approve photos in MDM TapCard → Admin → AutoGallery; approved photos then appear through the Netlify Function.
- `netlify/functions/mdm-gallery.js` securely proxies the API request, and `netlify.toml` configures Netlify to find it.

Main files:
- dist/index.html — page content, styling, and interactions
- dist/assets/mdm-logo.png — MDM Creation logo
- dist/assets/mdm-services.png — services overview image
